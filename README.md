# Movie Watchlist Manager

A simple Python project that helps me keep track of movies I want to watch and movies I have already watched.

I built this project to practice Python basics like lists, dictionaries, loops, conditions, and working with user input.

## Features

- Add new movies with their name and genre
- View all movies in the watchlist
- Search movies by name
- Mark movies as watched
- Delete movies from the list
- View statistics of watched and unwatched movies

## How it works

Movies are stored in a list of dictionaries. Each movie has a name, genre, and watching status.

The program runs through a menu where the user can choose what they want to do.

## Technologies Used

- Python
- Lists and dictionaries
- While loops and for loops
- Conditional statements
- User input
- Basic string methods

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the Python file:

```bash
python main.py
```
